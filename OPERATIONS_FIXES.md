## БД и переменные

Аддитивная миграция `free_daily_reports` добавляет `attempts` (по умолчанию 0),
`last_attempt_at`, `next_attempt_at`, `abandoned_at`, `abandon_reason`.
Пауза очереди хранится в существующей `bot_settings` под ключом
`free_daily_reports_retry_at`. Прежние поля и таблицы не удаляются.
Заказы и отчёты при закрытии сохраняются; удаляется только подтверждённо
неактуальное FREE-состояние. Миграция промокодов описана в BOT_IMPROVEMENTS.md.
При откате кода мигрированную SQLite нужно сохранить.

Новые эксплуатационные переменные в обоих `.env.example`:
`APEX_DOMAIN`, `PLATEGA_TRUSTED_PROXY_IP`, `HEALTH_PROBE_INTERVAL_SECONDS=60`,
`HEALTH_PROBE_MAX_AGE_SECONDS=180`. В серверный `.env` добавлен только отсутствующий
`APEX_DOMAIN`, определённый из прежнего Caddyfile. Compose задаёт фиксированный
адрес доверенного proxy. Новые домены и тарифы не вводились.

## Что требует владельца

1. Установить проверенный helper с sudo:
   `sudo install -m 755 /opt/jopesvpn/deploy/production/sync-hysteria2-cert.sh /usr/local/sbin/jopesvpn-sync-hysteria2-cert`.
   У агента нет passwordless sudo; установленный старый helper и timer продолжают работать.
2. Подтвердить фактические планы для десяти аккаунтов с неоднозначным TAG.
3. Выбрать Telegram-уведомления администраторам и постоянный внешний хост при необходимости.
   Сейчас используется локальный журнал. Задачи Windows требуют включённого ПК и входа пользователя.
4. Решить вопрос увеличения RAM при росте нагрузки. Платное изменение VPS не выполнялось.
5. Удалить вручную `C:\Users\Victus\JopesVPN-Backups\verified-restore.tar.gz`.
   Это незашифрованная проверочная копия с секретами в каталоге с ограниченным ACL.
   Автоматическая проверка заблокировала удаление с причиной «blocked by policy».
