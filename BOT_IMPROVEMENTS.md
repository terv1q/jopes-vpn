# Jopes VPN — отчёт об изменениях бота

## 1. Навигация

```text
Главное меню
├─ Настройка / подключение / пробный доступ — по текущему статусу
├─ Тарифы → категория → пакет → срок → существующие способы оплаты → результат
│  └─ Активировать промокод
├─ Личный кабинет
│  ├─ Подключение, устройства, настройки
│  ├─ Пополнение → сумма → существующие способы оплаты → результат
│  ├─ Платежи и операции, сотрудничество
│  └─ Активировать промокод
├─ Помощь
│  ├─ Инструкции → устройство → приложение → шаги подключения
│  ├─ Частые проблемы
│  ├─ Обращения → тема → сообщение → переписка / закрытие / оценка
│  └─ О сервисе → документы, канал, сообщество, отзывы
├─ Аккаунт и ещё → кабинет, устройства, статистика, тарифы, промокод,
│                   инструкции, информация о сервисе, операции, сотрудничество, настройки
├─ О сервисе
└─ Админ-панель → прежние разделы + промокоды для баланса

Подключение → Активировать промокод
Промокод → ввод → результат → тарифы / кабинет / другой код / назад / меню
```

«Назад» возвращает на предыдущий экран; без доступной истории открывается меню.
Выход с экрана закрывает ввод промокода, включая переход по старой кнопке покупки.
Операции удаления устройства больше не записываются как экраны истории.

Новые тексты промокодов написаны самостоятельно. Обновлены подсказка главного меню
без доступа, описание дополнительного меню и порядок действий в помощи; в помощи
показан Telegram ID для обращения. Сохранены оформление экранов, баннеры и механизм
их отправки. Исследовательские материалы использованы только для понимания переходов;
успешное применение промокода в них не зафиксировано.

## 3. БД и конфигурация

При запуске `PromoCodeStore` в существующей БД кошелька автоматически создаются
только три новые таблицы через `CREATE TABLE IF NOT EXISTS`:

| Таблица | Данные |
| --- | --- |
| `voucher_codes` | SHA-256 нормализованного кода, сумма подарка, срок UTC, квота, число применений, активность, автор |
| `voucher_redemptions` | Применения; уникальная пара «код + Telegram ID» |
| `voucher_attempt_windows` | Счётчики попыток пользователя и общий счётчик |

Миграция не изменяет схемы или строки прежних таблиц. Повторный запуск безопасен.
Проверка выполнена на временной БД с существующими таблицами и данными; рабочую БД
для выполнения миграции не открывали.

Промокод начисляет рублёвый подарок через текущий механизм кошелька. Начисление,
запись операции, применение и расход квоты фиксируются одной транзакцией SQLite
с `BEGIN IMMEDIATE`. При сбое всё откатывается. Существующая задолженность по
возвратам учитывается механизмом кошелька и поясняется пользователю.
При активации реферальное вознаграждение не начисляется; дальнейшие покупки
работают по текущим правилам сервиса. Тарифы, цены, сроки и платёжные способы сохранены.

Код применяется один раз на аккаунт, имеет обязательный срок и общую квоту.
Неверный формат тоже расходует попытку. По умолчанию доступны 5 проверок на аккаунт
и 300 проверок суммарно за окно 900 секунд. Лимиты сохраняются после перезапуска.
Неверный, истёкший, отключённый и исчерпанный код дают общее сообщение.
В БД сохраняется хеш кода, в журналы введённый код не попадает.

Новые переменные добавлены в оба `.env.example` и передаются контейнеру бота:

| Переменные | Назначение / значения по умолчанию |
| --- | --- |
| `BRAND_NAME` | Jopes VPN; название на новом экране бонуса |
| `COMMUNITY_URL`, `REVIEWS_URL`, `RESOURCES_URL` | Текущие ссылки Jopes VPN; пустое значение скрывает соответствующую кнопку |
| `PROMO_MIN_CODE_LENGTH`, `PROMO_MAX_CODE_LENGTH` | 8 / 48 символов; латиница, цифры, `-`, `_`, регистр не важен |
| `PROMO_MAX_ATTEMPTS`, `PROMO_GLOBAL_MAX_ATTEMPTS` | 5 / 300 проверок |
| `PROMO_ATTEMPT_WINDOW_SECONDS` | 900 секунд |
| `PROMO_MAX_REWARD_MINOR` | 100000 копеек — предел подарка при создании |
| `PROMO_MAX_VALID_DAYS`, `PROMO_MAX_USES` | 365 дней / 10000 применений — пределы при создании |

Прежние имена переменных сохранены. Ссылка на канал использует существующую
`TRIAL_CHANNEL_USERNAME`; имя бота в существующих ссылках определяется Telegram API.

## 4. Что требует решения владельца

Для каждой акции выберите сумму подарка, срок и число применений.
Коды по умолчанию не создаются. Администратор в личном чате с ботом может выполнить:

```text
/promo_create auto 50 7 10
/promo_create YOUR_ASCII_CODE 50 7 10
/promo_disable YOUR_ASCII_CODE
```

Первый пример создаёт случайный код: 50 ₽, срок 7 дней с момента создания,
10 разных аккаунтов. Значение `auto` предпочтительно для защиты от угадывания.
Повторное создание существующего кода не сбрасывает срок или квоту.
Отключение кода сохраняет уже выданные подарки. Технических блокеров нет.
